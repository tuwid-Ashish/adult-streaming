# StreamBox UI Prototype

This is a Next.js UI prototype featuring 3 distinct streaming platform interfaces: Velocity (Tube), Circle (Social), and Cinema (Premium).

## Features
- **3 UI Versions**: Toggle between different layout paradigms.
- **Dynamic Theming**: 5 unique themes across the versions using CSS variables.
- **Responsive Playback**: Responsive YouTube embeds for all videos.
- **Modern Tech**: Built with Next.js 14+, Tailwind CSS v4, and TypeScript.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Explore**:
   - Open [http://localhost:3000](http://localhost:3000)
   - Choose a version from the home switcher.
   - Use the **Theme Switcher** (palette icon) in the navigation bar to change themes.

## Version Specs
- **Velocity**: Desktop-first, dense grid, top search.
- **Circle**: Mobile-first, bottom nav, vertical feed, creator stories.
- **Cinema**: High-contrast black & gold, hero banners, carousels.
